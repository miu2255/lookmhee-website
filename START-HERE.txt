LOOKMHEE V3 — เพิ่มตัวแก้ไขบทความแบบไม่ต้องเขียนโค้ด

สิ่งที่เพิ่ม: admin.html (หน้ากรอกบทความในเครื่อง)

1. แตกไฟล์ ZIP
2. ดับเบิลคลิก admin.html (เปิดได้ในเบราว์เซอร์โดยไม่ต้องใช้เซิร์ฟเวอร์)
3. กดเลือกไฟล์ articles.json ที่อยู่ในโฟลเดอร์เดียวกัน
4. เลือกบทความที่ต้องการแก้ไข หรือกด + บทความใหม่
5. กรอกชื่อบทความ รหัส URL หมวดหมู่ คำอธิบาย เนื้อหา แล้วกดบันทึกในตัวแก้ไข
6. กดดาวน์โหลด articles.json แล้วนำไฟล์นี้แทน articles.json เดิมในโฟลเดอร์เว็บไซต์
7. อัปโหลดไฟล์ articles.json ที่แก้แล้วไปยัง Cloudflare Pages / เว็บโฮสต์

ข้อจำกัด: admin.html ไม่ได้เชื่อมกับบัญชีผู้ใช้หรือฐานข้อมูลออนไลน์
ไม่มีปุ่มเผยแพร่อัตโนมัติ ต้องอัปโหลด articles.json เอง
อย่าอัปโหลด admin.html ไปยังเว็บไซต์สาธารณะ เพราะไม่มีระบบล็อกอิน
ควรสำรอง articles.json เดิมก่อนเขียนทับ

หากต้องการเพิ่มบทความแล้วกดเผยแพร่ได้ทันที ขั้นต่อไปต้องเชื่อม CMS ที่มีระบบยืนยันตัวตน เช่น Pages CMS กับ GitHub และระบบ Deploy

หมายเหตุ: บทความตัวอย่างเป็นเพียงข้อมูลทดสอบ ยังไม่ควรนำเผยแพร่เป็นข้อมูลวิชาการโดยไม่ตรวจสอบข้อเท็จจริง
